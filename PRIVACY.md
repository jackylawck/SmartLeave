## 🇭🇰 繁體中文

**生效日期**：2026 年 8 月 11 日  
**專案名稱**：SmartLeave 智休假

SmartLeave 致力於保護使用者的資料隱私。本專案嚴格遵守 **香港《個人資料（隱私）條例》（PDPO）** 及 **歐盟《通用資料保護規則》（GDPR）** 之「預設隱私保護」（Privacy by Design & Default）原則。

### 1. 零資料收集與本地運算 (Zero Data Retention)
* **純客戶端處理**：本應用程式為 100% 純前端架構。您輸入的年假（AL）天數、請假偏好及下載的日曆檔（`.ics`），完全於您的瀏覽器本地（Client-Side）完成運算。
* **無伺服器儲存**：我們不設後端資料庫，絕不傳送、收集、記錄或追蹤您的任何個人請假數據。

### 2. 外部 API 與數據傳輸
本應用僅向公開且不具追蹤性的第三方 API 發送請求（如香港天文台 HKO、Open-Meteo 及歐洲央行匯率 API）。所有 API 請求均不包含任何使用者個人識別資訊（PII）。

### 3. PWA 離線快取 (Service Worker)
本系統使用 PWA 快取技術（Service Worker），僅用於快取應用程式靜態資源（如 HTML/JS 檔案），以提供離線使用功能，絕不利用快取收集個人隱私。

## 🇬🇧 English

**Effective Date**: August 11, 2026  
**Project Name**: SmartLeave

SmartLeave is committed to user privacy. This project strictly complies with the **Privacy by Design & Default** principles outlined in the **Hong Kong Personal Data (Privacy) Ordinance (PDPO)** and the **EU General Data Protection Regulation (GDPR)**.

### 1. Zero Data Retention & Local Processing
* **Client-Side Operation**: SmartLeave runs 100% on the client side. Your Annual Leave (AL) inputs, leave preferences, and exported calendar files (`.ics`) are processed entirely inside your local browser.
* **No Server Storage**: We operate without backend databases. No personally identifiable information (PII) or leave patterns are ever transmitted, collected, recorded, or shared.

### 2. External APIs & Data Transmission
Requests are sent exclusively to public, non-tracking data sources (e.g., Hong Kong Observatory, Open-Meteo, European Central Bank FX rates). No PII or user metadata is included in these requests.

### 3. Offline Service Worker Cache
Service Worker technology is used strictly to cache static application assets (HTML/JS) for offline functionality. It does not track, store, or profile user activities.
